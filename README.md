## Para inicar el proyecto localmente

```bash
pnpm install
pnpm dev
```

Abrir [http://localhost:3000](http://localhost:3000) para ver el resultado

## Acerca del proyecto

Hecho como freelance para promocionar un servicio de `Cortinas Metálicas`.

La aplicación usa [`Nextjs`](https://nextjs.org/docs) para el frontend y la ruta _API_ para ciertas interacciones con servicios de terceros y un mini _dashboard_ de uso personal para el cliente.
